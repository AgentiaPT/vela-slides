# Reporting a problem

RULE problem-report. WHEN opening a report.
DO first search the existing list — nobody already reported this.
EXC match found ⇒ add your details there; NEVER open a second report.
MUST include ALL of: exact command run · version · full output.
WHY a report missing any of those three things cannot be acted on ⇒ closed.
REF before you start: [reporting guide](https://example.com/docs/reporting/guide.html) · [style rules][style].
NOTE archived triage notes, still accurate: https://example.com/archive/2019/triage-notes.html
NEVER paste credentials · tokens · customer data.
DO redact first if output you want to attach contains ANY of those.

[style]: https://example.com/docs/style/index.html "Style rules"
[triage]: https://example.com/docs/triage/index.html
