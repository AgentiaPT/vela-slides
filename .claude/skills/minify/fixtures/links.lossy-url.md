# Reporting a problem

RULE problem-report.
WHEN opening a problem report.
DO first search the existing list — nobody has already reported the same problem.
EXC a matching report exists ⇒ add your details to it; NEVER open a second one.
MUST include ALL of: exact command you ran · version you are running · full output.
WHY a report missing any of those three cannot be acted on and will be closed.
REF read before you start: [reporting guide](https://example.com/docs/reporting/guide.html) · [style rules][style].
NOTE archived triage notes — still accurate — at https://example.com/archive/triage-notes
NEVER paste credentials · tokens · customer data into a report.
DO redact them first if the output you want to attach contains ANY of those.

[style]: https://example.com/docs/style/
[triage]: https://example.com/docs/triage/index.html
